## Prinzipien

| Prinzip | Bedeutung |
|---|---|
| **Local-First** | Daten, Persistenz und Werkzeuge bleiben auf eigener Hardware — kein Cloud-Zwang |
| **Privacy-First** | Lokale KI-Inferenz (Ollama) statt Cloud-LLMs für produktive Nutzdaten |
| **Zero-Trust** | Kein offenes Port-Forwarding — Zugriff intern über Tailscale und kontrolliert per Cloudflare Tunnel |
| **80/20-Konsistenz** | Pragmatische, wartbare Lösungen vor theoretischer Überkonstruktion |
